Cost categories

Direct cost

Costs directly attributed to an agent or workload via tags.

Detected by: `agent_id` or `workload_id` tags, or cost_category/allocation_scope=direct.

Allocation: mapped 100% to the tagged agent/workload.

Total for selected period: {{ reporting_context.currency_symbol }}{{ '%.2f' % totals.direct }}

Indirect cost

Shared costs allocated across agents based on usage metrics.

Detected by: cost_category/allocation_scope=indirect.

Allocation: by `log_volume_gb` (fallback to `request_count`).

Total for selected period: {{ reporting_context.currency_symbol }}{{ '%.2f' % totals.indirect }}

Platform cost

Platform-level shared costs (storage, infra) allocated by weighted usage.

Detected by: cost_category/allocation_scope=platform or shared_service + distribution_key.

Allocation: weighted usage (token, runtime, tool-call shares).

Total for selected period: {{ reporting_context.currency_symbol }}{{ '%.2f' % totals.platform }}

Unallocated cost

Costs that lack required attribution metadata and are kept visible.

Detected by: missing `agent_id` / `workload_id` / distribution keys.

Action: kept visible and not silently assigned.

Total for selected period: {{ reporting_context.currency_symbol }}{{ '%.2f' % totals.unallocated }}
